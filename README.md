# Snake

### A pseudo functional javascript snake

This is an attempt to rewrite the classic game snake, following functional programming principles. You can play it at [https://ptrpiero.github.io/snake/](https://ptrpiero.github.io/snake/)

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | Arrow keys or WASD | Swipe |
| Start / pause / resume / play again | Space or P | Button (tap the board to start or resume) |
| Pause | Escape | Button |
| Restart | R | Restart button |

The game pauses automatically when the tab is hidden. It ends when the snake collides with itself, and is won when the snake fills the board.
